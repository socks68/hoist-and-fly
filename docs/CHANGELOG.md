# Changelog

## 1.1.0 (29 October 2026)

- Dark mode is now the default for everyone, regardless of device or Claude theme settings.
- Added a light/dark switch to the header (also on phones). Each device remembers its own choice.
- Self-hostable build (`site/`): a complete HTML document with a favicon, social preview text and a credit line for the flag artwork.
- Repository with build tools, an end-to-end test and documentation.
- Released under the MIT License. The flag images keep the license of the worldflags package (LPPL 1.3).

## 1.0.0 (29 October 2026)

First release, published as a Claude artifact.

- All 197 flags (193 UN members, Vatican City, Palestine, Kosovo, Taiwan), each drawn to official proportions, with the story behind the design, a recognition tip, a fact and its lookalikes.
- Current flags for Afghanistan (2021), Kyrgyzstan (2023) and Syria (2025), with their previous or alternative designs on the detail pages.
- Explore: search, filters by region, colour, layout and symbol, and five sort orders.
- Quiz: three modes, any continent, Standard or Tricky wrong answers, five lives, results with the flags you missed.
- Flashcards with requeueing, decks by region, mastery or custom sets.
- Lookalikes: 23 groups with the detail that tells each pair apart.
- Learn: parts of a flag, proportions, glossary, ten flag families, 18 records and oddities.
- Progress tracking (mastered after three correct answers in a row), saved in the browser and, on Claude, to the viewer's account.
- Layout for phones with a bottom tab bar; keyboard shortcuts on desktop.
